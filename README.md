AE Color Swatches Panel

Custom ScriptUI panel for Adobe After Effects to manage color libraries efficiently.

Features
- Swatches system (up to 8 colors per library)
- Multiple libraries
- JSON persistence
- HEX input + color picker
- Apply colors directly to selected properties
- Delete / Rename libraries


Installation: Copy `.jsx` file into: After Effects > Scripts > ScriptUI Panels
Open in: Window → Color Swatches


Usage
- Add colors via picker or HEX
- Double-click swatch to apply color
- Right-click to delete
- Manage libraries with + / - / Rename

Tech
- ExtendScript
- ScriptUI
- Adobe After Effects API

Suggestions and improvements are welcome.
